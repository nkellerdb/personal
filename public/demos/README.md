# Exercise demos

Drop GIF / MP4 / WebM files here. A card uses, in order:

1. the `demo.file` named for that exercise in `src/program.json`, or
2. `<exercise-id>.mp4`, `.webm` or `.gif` (e.g. `squat.mp4`, `rdl.gif`),
3. otherwise the exercise's `demo.youtube` link.

Keep clips short (3–6 s loops, < 2 MB) — they're cached for offline use the first time you open them.
